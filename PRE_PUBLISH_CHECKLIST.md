# Makmur Lab — Pre-Publish Checklist

## Content
- [ ] Homepage message represents me accurately.
- [ ] About page is current.
- [ ] LinkedIn link works.
- [ ] Public email has been added or intentionally omitted.
- [ ] Project role descriptions distinguish my work from team/company work.
- [ ] No unverified impact metrics are presented as facts.

## Confidentiality
- [ ] No supplier prices.
- [ ] No confidential contract clauses.
- [ ] No private company production data.
- [ ] No personal employee/vendor data.
- [ ] No internal drawings or files.
- [ ] Screenshots have been sanitized or replaced with mockups.

## Technical
- [ ] Home works.
- [ ] About works.
- [ ] Projects works.
- [ ] Notes works.
- [ ] Procurement Control Tower works.
- [ ] 404 works.
- [ ] Mobile navigation works.
- [ ] Dark/light mode works.
- [ ] No broken local links.
- [ ] Favicon appears.
- [ ] Page titles and descriptions are correct.

## After final domain is chosen
- [ ] Add canonical URLs.
- [ ] Add og:url.
- [ ] Add absolute social-card URL.
- [ ] Add sitemap.xml.
- [ ] Add Sitemap line to robots.txt.
- [ ] Configure HTTPS/custom domain in hosting provider.
